How Java is different from other languages?
   
    Java is different from other languages beacause it is platform independent.
    Java programs can run on any OS like windows,linux or Mac beacause Java uses JVM(Java Virtual Machine).
    It is object-oriented,strong secure,robust and protable.

Explain public static void main(String[] args)
   
    public static void main(String[] args) - starting point of the program.
    public - It allows JVM to access the method
    static - It allows running without creating the object.
    void   - It does not return any value.
    main   - It is the method name where the execution starts.
    (String[] args) -used to pass command line arguments.


Sample program:

   class Patternprog
   {
   public static void main(String[] args)
   {
     System.out.println("***");
     System.out.println("*****");
   }
   }
